# 111 Domain AI Requirements

## 学ぶこと

- 特化型AIは「何でも答えるAI」ではなく、対象業務を絞って作る
- in-scope / out-of-scope を先に決める
- 成功条件、禁止事項、利用者を明文化する

## 書くこと

- 要件から不足項目を見つける
- taskが対象範囲内か判定する
- AI化に向く/向かない理由を返す
