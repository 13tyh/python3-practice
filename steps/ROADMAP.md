# Roadmap

## Phase 1: Python の土台

- `00_environment` から `04_datetime_timezone`
- 基本文法、型、ファイル、日時を手で書ける
- 小さい関数の入力、出力、例外を説明できる

## Phase 2: テストと設計

- `05_testing_deep` から `14_advanced`
- テストから仕様を読む
- logger、責務分割、リファクタリング、Repositoryを判断できる

## Phase 3: FastAPI とAPI実務

- `15_pydantic_validation` から `27_processes`
- FastAPI の schema/router/service を分ける
- 認証、例外、API設計、HTTP、async、subprocessを読める

## Phase 4: DB、性能、データ処理

- `28_performance` から `42_log_analysis`
- N+1、index、transaction、cache、job、CSV/PDF/分析を扱える
- mongosh で seed データを確認し、集計できる

## Phase 5: AI/RAG

- `43_model_mapping` から `55_ai_agents`
- deployment_name と model_name を分ける
- LangChain / LangGraph / RAG / batch / evaluation を説明できる

## Phase 6: 統合とレビュー

- `56_fastapi_ai`、`57_ai_review`、`58_capstone`
- FastAPI から AI service を呼ぶ設計を説明できる
- AI の実装をそのまま貼らず、仕様差分、境界値、テスト不足を指摘できる
