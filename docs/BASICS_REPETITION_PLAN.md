## ルール

- 1 round 15分を目安にする
- 失敗したら error message を読む
- 解けなかった関数名を `design_memos/` に残す
- 翌日に同じ round をもう一度解く

## 見る観点

- 入力の型
- 戻り値の型
- 空文字 / 空 list / None
- 元の list / dict を変更していないか
- 例外を出すべきか、値を返すべきか
